# USBPhone Control

A handwritten Android USB toolkit for the observe → act → observe loop: screenshots, accessibility elements, taps, swipes, typing and app launches. Independent Python API, CLI and optional MCP interface.

The companion [GraphPilot agent](https://github.com/obsessed-star/graphpilot-agent) uses this package without coupling the transport to any model provider. Requires Android Platform Tools and an owner-authorized USB debugging connection; iOS is outside this project's scope.
